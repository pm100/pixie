# Videos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Index, show, thumbnail and play phone/camera videos (MP4, MOV, M4V) in the existing library, with an All | Photos | Videos filter.

**Architecture:** Videos are rows in the existing `photos` table with a `kind` and `duration_ms` (V3 migration), so grid, date tree, folder tree, selection and details work unchanged. Metadata comes from `nom-exif` (pure Rust) plus a small `tkhd` parser for rotation. The webview plays files through a range-capable `pixie:/video/{id}` route and makes its own poster frames, which it saves back through a command; `pixie:/poster/{id}` serves them.

**Tech Stack:** Rust (`nom-exif` 3, rusqlite, tauri 2, `tauri-plugin-opener`), Svelte 5 + TypeScript.

**Spec:** `docs/superpowers/specs/2026-10-16-videos-design.md`

## Global Constraints

- **AGENTS.md: never commit or push unless the user says so.** This plan has no commit steps.
- Never kill the user's running `pixie-app.exe`; never touch `%APPDATA%\app.pixie.desktop\`. While the app runs, `cargo build -p pixie-app` cannot replace the exe: use `cargo check -p pixie-app` (the user's `tauri dev` rebuilds).
- Use `npm run tauri ...` (local v2), never global `cargo tauri`. Never run plain `cargo update`.
- Rust env per session: `VCPKG_ROOT=C:/work/vcpkg-pixie`, `VCPKGRS_TRIPLET=x64-windows-static-md`, `CARGO_RESOLVER_INCOMPATIBLE_RUST_VERSIONS=fallback`.
- **Never commit personal videos.** Test fixtures are generated in code (Task 3). Real videos under `C:\Users\paulm\OneDrive\Pictures` may be read (read-only) by ignored/live checks only.
- Video extensions: `mp4`, `mov`, `m4v` (case-insensitive); `._name` resource-fork files are ignored. All served as `video/mp4`. Range responses are capped at 4 MiB (`RANGE_CHUNK = 4 * 1024 * 1024`).
- Poster limits: JPEG, at most 2 MiB, at most 512 px on a side. Poster frame time `min(1 s, duration / 2)`. Player timeout 8 s.
- Poster file name: `{id}-{mtime}-{size}.jpg` in `<app data>/posters/`.
- UTC creation times get shifted by `round(longitude / 15)` hours when GPS is present (approximate local time, matching how photo dates are stored: local-as-UTC).

## Review Focus

- Large files: range serving never reads more than 4 MiB per request.
- Corrupt, truncated and zero-byte `.mp4`/`.mov` are indexed (kind video, mtime date) and never stop a scan.
- Rotated (portrait) videos report swapped width/height.
- Poster generation: one `<video>` at a time, always torn down, no retry loop on failure.
- Leaving a playing video (arrow, Escape, filter change) stops it.
- `/video/{id}`, `/poster/{id}` and `save_poster` resolve by database id only; no path from the webview is ever opened.

```rust
pub const VIDEO_EXTENSIONS: &[&str] = &["mp4", "mov", "m4v"];

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum MediaKind {
    #[default]
    Photo,
    Video,
}

fn has_extension_in(path: &Path, list: &[&str]) -> bool {
    let name = path.file_name().and_then(|n| n.to_str()).unwrap_or("");
    if name.starts_with("._") {
        return false;
    }
    path.extension()
        .and_then(|e| e.to_str())
        .map(|e| list.contains(&e.to_ascii_lowercase().as_str()))
        .unwrap_or(false)
}

/// True for supported video files. Ignores macOS `._name` resource-fork files.
pub fn is_supported_video(path: &Path) -> bool {
    has_extension_in(path, VIDEO_EXTENSIONS)
}

/// Photo or video, by extension; `None` for anything Pixie does not index.
pub fn media_kind(path: &Path) -> Option<MediaKind> {
    if is_supported_image(path) {
        Some(MediaKind::Photo)
    } else if is_supported_video(path) {
        Some(MediaKind::Video)
    } else {
        None
    }
}
```

```rust
struct Filter {
    folder: Option<i64>,
    kind: Option<i64>,
}

impl Filter {
    fn of(q: &PhotoQuery) -> Filter {
        Filter {
            folder: q.folder_id,
            kind: q.kind.map(|k| if k == MediaKind::Video { 1 } else { 0 }),
        }
    }
    fn sql(&self) -> String {
        let mut s = String::new();
        if self.folder.is_some() {
            s.push_str(" AND folder_id = :folder");
        }
        if self.kind.is_some() {
            s.push_str(" AND kind = :kind");
        }
        s
    }
    fn params(&self) -> Vec<(&'static str, &dyn rusqlite::ToSql)> {
        let mut v: Vec<(&'static str, &dyn rusqlite::ToSql)> = Vec::new();
        if let Some(f) = &self.folder {
            v.push((":folder", f));
        }
        if let Some(k) = &self.kind {
            v.push((":kind", k));
        }
        v
    }
}
```

```rust
/// What to put in a synthetic MP4. Boxes are valid ISO base media, not playable video.
#[derive(Clone, Default)]
pub struct Mp4Spec {
    pub width: u32,
    pub height: u32,
    pub duration_ms: u32,
    /// Seconds since 1904-01-01 (MP4 epoch); 0 = unset.
    pub created_1904: u64,
    /// 0, 90, 180 or 270 degrees clockwise.
    pub rotation: u16,
    /// ISO 6709 string such as "+20.6858-156.4440/".
    pub iso6709: Option<String>,
    /// Put `moov` after a dummy `mdat` (a non-"faststart" file).
    pub moov_last: bool,
}

fn bx(kind: &[u8; 4], payload: &[u8]) -> Vec<u8> {
    let mut v = ((payload.len() + 8) as u32).to_be_bytes().to_vec();
    v.extend_from_slice(kind);
    v.extend_from_slice(payload);
    v
}

fn fixed(v: i32) -> [u8; 4] {
    v.to_be_bytes()
}

pub fn mp4(s: &Mp4Spec) -> Vec<u8> {
    let ftyp = bx(b"ftyp", &[b"isom".as_slice(), &[0, 0, 2, 0], b"isomiso2mp41"].concat());
    // mvhd v0
    let mut mvhd = vec![0u8; 4];
    mvhd.extend_from_slice(&(s.created_1904 as u32).to_be_bytes());
    mvhd.extend_from_slice(&(s.created_1904 as u32).to_be_bytes());
    mvhd.extend_from_slice(&1000u32.to_be_bytes()); // timescale
    mvhd.extend_from_slice(&s.duration_ms.to_be_bytes());
    mvhd.extend_from_slice(&[0, 1, 0, 0, 1, 0, 0, 0]); // rate 1.0, volume 1.0, reserved
    mvhd.extend_from_slice(&[0u8; 8]);
    for m in [0x10000, 0, 0, 0, 0x10000, 0, 0, 0, 0x4000_0000] {
        mvhd.extend_from_slice(&fixed(m));
    }
    mvhd.extend_from_slice(&[0u8; 24]); // pre_defined
    mvhd.extend_from_slice(&2u32.to_be_bytes()); // next track id
    let mvhd = bx(b"mvhd", &mvhd);
    // tkhd v0 with a rotation matrix
    let (a, b, c, d) = match s.rotation % 360 {
        90 => (0, 0x10000, -0x10000, 0),
        180 => (-0x10000, 0, 0, -0x10000),
        270 => (0, -0x10000, 0x10000, 0),
        _ => (0x10000, 0, 0, 0x10000),
    };
    let mut tkhd = vec![0, 0, 0, 3];
    tkhd.extend_from_slice(&(s.created_1904 as u32).to_be_bytes());
    tkhd.extend_from_slice(&(s.created_1904 as u32).to_be_bytes());
    tkhd.extend_from_slice(&1u32.to_be_bytes()); // track id
    tkhd.extend_from_slice(&[0u8; 4]);
    tkhd.extend_from_slice(&s.duration_ms.to_be_bytes());
    tkhd.extend_from_slice(&[0u8; 8]);
    tkhd.extend_from_slice(&[0u8; 8]); // layer, alt group, volume, reserved
    for m in [a, b, 0, c, d, 0, 0, 0, 0x4000_0000] {
        tkhd.extend_from_slice(&fixed(m));
    }
    tkhd.extend_from_slice(&((s.width) << 16).to_be_bytes());
    tkhd.extend_from_slice(&((s.height) << 16).to_be_bytes());
    let trak = bx(b"trak", &bx(b"tkhd", &tkhd));
    let mut moov_payload = [mvhd, trak].concat();
    if let Some(loc) = &s.iso6709 {
        let mut xyz = (loc.len() as u16).to_be_bytes().to_vec();
        xyz.extend_from_slice(&[0x15, 0xc7]); // language
        xyz.extend_from_slice(loc.as_bytes());
        moov_payload.extend(bx(b"udta", &bx(&[0xa9, b'x', b'y', b'z'], &xyz)));
    }
    let moov = bx(b"moov", &moov_payload);
    let mdat = bx(b"mdat", &[0u8; 64]);
    if s.moov_last {
        [ftyp, mdat, moov].concat()
    } else {
        [ftyp, moov, mdat].concat()
    }
}
```

```rust
const MAX_MOOV: u64 = 64 * 1024 * 1024;

/// (width, height) of the first track with a picture size, and whether the track
/// is rotated a quarter turn (so the displayed size swaps).
struct Tkhd {
    width: u32,
    height: u32,
    quarter_turn: bool,
}

fn be32(b: &[u8], at: usize) -> Option<u32> {
    Some(u32::from_be_bytes(b.get(at..at + 4)?.try_into().ok()?))
}

/// Child boxes of `data`: (type, payload).
fn children(data: &[u8]) -> Vec<([u8; 4], &[u8])> {
    let mut out = Vec::new();
    let mut at = 0usize;
    while at + 8 <= data.len() {
        let size = be32(data, at).unwrap_or(0) as usize;
        let kind: [u8; 4] = data[at + 4..at + 8].try_into().unwrap();
        let (header, end) = match size {
            0 => (8, data.len()),
            1 => (16, data.get(at + 8..at + 16).map(|b| u64::from_be_bytes(b.try_into().unwrap()) as usize).map_or(data.len(), |s| at.saturating_add(s))),
            n => (8, at.saturating_add(n)),
        };
        if end > data.len() || end < at + header {
            break;
        }
        out.push((kind, &data[at + header..end]));
        at = end;
    }
    out
}

fn parse_tkhd(p: &[u8]) -> Option<Tkhd> {
    let v1 = *p.first()? == 1;
    let matrix_at = if v1 { 52 } else { 40 };
    let (a, b) = (be32(p, matrix_at)? as i32, be32(p, matrix_at + 4)? as i32);
    let (c, d) = (be32(p, matrix_at + 12)? as i32, be32(p, matrix_at + 16)? as i32);
    let size_at = matrix_at + 36;
    let width = be32(p, size_at)? >> 16;
    let height = be32(p, size_at + 4)? >> 16;
    Some(Tkhd { width, height, quarter_turn: a == 0 && d == 0 && b != 0 && c != 0 })
}

/// Reads only the `moov` box (wherever it is) and finds the first picture track.
fn read_tkhd(path: &Path) -> Option<Tkhd> {
    let mut f = std::fs::File::open(path).ok()?;
    let len = f.metadata().ok()?.len();
    let mut pos = 0u64;
    while pos + 8 <= len {
        f.seek(SeekFrom::Start(pos)).ok()?;
        let mut h = [0u8; 16];
        let got = f.read(&mut h).ok()?;
        if got < 8 {
            return None;
        }
        let size32 = u32::from_be_bytes(h[0..4].try_into().unwrap()) as u64;
        let (header, size) = match size32 {
            0 => (8, len - pos),
            1 if got >= 16 => (16, u64::from_be_bytes(h[8..16].try_into().unwrap())),
            n => (8, n),
        };
        if size < header || pos + size > len {
            return None;
        }
        if &h[4..8] == b"moov" {
            if size - header > MAX_MOOV {
                return None;
            }
            f.seek(SeekFrom::Start(pos + header)).ok()?;
            let mut buf = vec![0u8; (size - header) as usize];
            f.read_exact(&mut buf).ok()?;
            return children(&buf)
                .into_iter()
                .filter(|(k, _)| k == b"trak")
                .filter_map(|(_, trak)| {
                    children(trak).into_iter().find(|(k, _)| k == b"tkhd").and_then(|(_, p)| parse_tkhd(p))
                })
                .find(|t| t.width > 0 && t.height > 0);
        }
        pos += size;
    }
    None
}

/// UTC seconds shifted to approximate local time using longitude (15 degrees per hour).
/// Photo dates are stored as local-as-UTC, so videos need the same convention to land
/// on the same day.
pub fn approx_local(utc_secs: i64, lon: Option<f64>) -> i64 {
    match lon {
        Some(l) if l.is_finite() && l.abs() <= 180.0 => utc_secs + (l / 15.0).round() as i64 * 3600,
        _ => utc_secs,
    }
}

fn sanitize(lat: Option<f64>, lon: Option<f64>) -> (Option<f64>, Option<f64>) {
    match (lat, lon) {
        (Some(a), Some(o))
            if a.is_finite() && o.is_finite() && a.abs() <= 90.0 && o.abs() <= 180.0 && !(a == 0.0 && o == 0.0) =>
        {
            (Some(a), Some(o))
        }
        _ => (None, None),
    }
}

/// Best-effort metadata for a video; never fails. Dimensions are as displayed.
pub fn read_video_meta(path: &Path) -> PhotoMeta {
    let mut meta = PhotoMeta { kind: MediaKind::Video, ..Default::default() };
    let tkhd = read_tkhd(path);
    if let Some(t) = &tkhd {
        let (w, h) = if t.quarter_turn { (t.height, t.width) } else { (t.width, t.height) };
        meta.width = Some(w);
        meta.height = Some(h);
    }
    let Ok(info) = read_track(path) else { return meta };
    meta.duration_ms = info.get(TrackInfoTag::DurationMs).and_then(|v| v.as_u64()).map(|v| v as i64);
    meta.camera = info.get(TrackInfoTag::Model).and_then(|v| v.as_str()).map(str::to_owned).filter(|s| !s.is_empty());
    if tkhd.is_none() {
        meta.width = info.get(TrackInfoTag::Width).and_then(|v| v.as_u32());
        meta.height = info.get(TrackInfoTag::Height).and_then(|v| v.as_u32());
    }
    if let Some(g) = info.gps_info() {
        (meta.gps_lat, meta.gps_lon) = sanitize(g.latitude_decimal(), g.longitude_decimal());
    }
    meta.taken_at = info
        .get(TrackInfoTag::CreateDate)
        .and_then(|v| v.as_datetime())
        .map(|d| match d.aware() {
            Some(dt) => dt.timestamp(),
            None => d.into_naive().and_utc().timestamp(),
        })
        .filter(|t| *t > 0)
        .map(|t| approx_local(t, meta.gps_lon));
    meta
}
```

```rust
/// Plan the byte range for a `Range` request header. A missing or unparseable header
/// means the first chunk: browsers always send `Range` for `<video>`, and sending a
/// whole multi-gigabyte file in one response is never what we want.
pub fn plan_range(header: Option<&str>, size: u64) -> RangePlan {
    if size == 0 {
        return RangePlan::Unsatisfiable;
    }
    let last = size - 1;
    let first_chunk = RangePlan::Partial { start: 0, end: last.min(RANGE_CHUNK - 1) };
    let Some(spec) = header.and_then(|h| h.trim().strip_prefix("bytes=")) else { return first_chunk };
    if spec.contains(',') {
        return first_chunk;
    }
    let Some((a, b)) = spec.split_once('-') else { return first_chunk };
    let (a, b) = (a.trim(), b.trim());
    let cap = |start: u64, end: u64| RangePlan::Partial { start, end: end.min(start + RANGE_CHUNK - 1).min(last) };
    match (a.is_empty(), b.is_empty()) {
        (true, true) => first_chunk,
        (true, false) => match b.parse::<u64>() {
            Ok(0) => RangePlan::Unsatisfiable,
            Ok(n) => cap(size.saturating_sub(n), last),
            Err(_) => first_chunk,
        },
        (false, true) => match a.parse::<u64>() {
            Ok(s) if s <= last => cap(s, last),
            Ok(_) => RangePlan::Unsatisfiable,
            Err(_) => first_chunk,
        },
        (false, false) => match (a.parse::<u64>(), b.parse::<u64>()) {
            (Ok(s), Ok(e)) if s > last || e < s => RangePlan::Unsatisfiable,
            (Ok(s), Ok(e)) => cap(s, e),
            _ => first_chunk,
        },
    }
}

/// The bytes `start..=end` of a file. Reads exactly that slice, never the whole file.
pub fn read_range(path: &Path, start: u64, end: u64) -> std::io::Result<Vec<u8>> {
    let mut f = std::fs::File::open(path)?;
    f.seek(SeekFrom::Start(start))?;
    let mut buf = Vec::with_capacity((end - start + 1) as usize);
    f.take(end - start + 1).read_to_end(&mut buf)?;
    Ok(buf)
}
```

```rust
}

/// A poster must be a JPEG of at most 2 MiB and 512 px on a side. The bytes come from
/// the webview, so nothing else is accepted.
pub fn validate_poster(bytes: &[u8]) -> Result<(), &'static str> {
    if bytes.is_empty() || bytes.len() > MAX_POSTER_BYTES {
        return Err("poster has an unreasonable size");
    }
    if bytes.len() < 4 || bytes[0] != 0xFF || bytes[1] != 0xD8 {
        return Err("poster is not a JPEG");
    }
    let (w, h) = image::ImageReader::with_format(std::io::Cursor::new(bytes), image::ImageFormat::Jpeg)
        .into_dimensions()
        .map_err(|_| "poster is not a readable JPEG")?;
    if w == 0 || h == 0 || w > MAX_POSTER_SIDE || h > MAX_POSTER_SIDE {
        return Err("poster dimensions are out of range");
    }
    Ok(())
}

pub fn save_poster(path: &Path, bytes: &[u8]) -> std::io::Result<()> {
    if let Some(parent) = path.parent() {
        std::fs::create_dir_all(parent)?;
    }
    let tmp = path.with_extension("tmp");
    std::fs::write(&tmp, bytes)?;
    std::fs::rename(&tmp, path)
}
```

```rust
/// a slow disk or OneDrive placeholder never blocks the protocol handler.
fn handle_video(state: &AppState, path: &str, range: Option<String>, responder: tauri::UriSchemeResponder) {
    let Some(id) = path.trim_matches('/').split('/').nth(1).and_then(|s| s.parse::<i64>().ok()) else {
        return responder.respond(status(StatusCode::NOT_FOUND));
    };
    let photo = match state.db.get_photo(id) {
        Ok(Some(p)) if p.meta.kind == MediaKind::Video => p,
        Ok(_) => return responder.respond(status(StatusCode::NOT_FOUND)),
        Err(_) => return responder.respond(status(StatusCode::INTERNAL_SERVER_ERROR)),
    };
    std::thread::spawn(move || {
        let size = match std::fs::metadata(&photo.path) {
            Ok(m) => m.len(),
            Err(_) => return responder.respond(status(StatusCode::NOT_FOUND)),
        };
        match plan_range(range.as_deref(), size) {
            RangePlan::Unsatisfiable => responder.respond(
                Response::builder()
                    .status(StatusCode::RANGE_NOT_SATISFIABLE)
                    .header("Content-Range", format!("bytes */{size}"))
                    .body(Vec::new())
                    .unwrap(),
            ),
            RangePlan::Partial { start, end } => match read_range(std::path::Path::new(&photo.path), start, end) {
                Ok(bytes) => responder.respond(video_response(bytes, start, end, size)),
                Err(e) => {
                    eprintln!("[video] {}: {e}", photo.path);
                    responder.respond(status(StatusCode::INTERNAL_SERVER_ERROR));
                }
            },
        }
    });
}
```

```ts
/**
 * Makes poster frames one at a time. The newest request runs first (it is what the user
 * is looking at); a failed id is never retried in this session.
 */
export function createPosterQueue(run: (id: number) => Promise<boolean>) {
  const waiting: number[] = [];
  const waiters = new Map<number, ((ok: boolean) => void)[]>();
  const failed = new Set<number>();
  let running: number | null = null;

  function settle(id: number, ok: boolean) {
    if (!ok) failed.add(id);
    for (const w of waiters.get(id) ?? []) w(ok);
    waiters.delete(id);
  }

  async function pump() {
    if (running !== null) return;
    const id = waiting.pop();
    if (id === undefined) return;
    running = id;
    let ok = false;
    try {
      ok = await run(id);
    } catch {
      ok = false;
    }
    running = null;
    settle(id, ok);
    void pump();
  }

  return {
    request(id: number): Promise<boolean> {
      if (failed.has(id)) return Promise.resolve(false);
      return new Promise<boolean>((resolve) => {
        const list = waiters.get(id);
        if (list) list.push(resolve);
        else waiters.set(id, [resolve]);
        if (id !== running && !waiting.includes(id)) waiting.push(id);
        void pump();
      });
    },
    /** Drop a job that has not started (its tile scrolled away). */
    cancel(id: number) {
      const i = waiting.indexOf(id);
      if (i >= 0) {
        waiting.splice(i, 1);
        for (const w of waiters.get(id) ?? []) w(false);
        waiters.delete(id);
      }
    },
  };
}
```

Note `cancel` resolves waiters with `false` but does not add the id to `failed` (it may be requested again).

```ts
const TIMEOUT_MS = 8000;
const MAX_SIDE = 360;

/** Decodes one frame of the video with the webview's own player and saves it as the poster. */
export function makePoster(p: Photo): Promise<boolean> {
  return new Promise((resolve) => {
    const v = document.createElement('video');
    v.muted = true;
    v.preload = 'metadata';
    v.crossOrigin = 'anonymous';
    let done = false;
    const finish = (ok: boolean) => {
      if (done) return;
      done = true;
      clearTimeout(timer);
      v.removeAttribute('src'); // always tear the decoder down
      v.load();
      resolve(ok);
    };
    const timer = setTimeout(() => finish(false), TIMEOUT_MS);
    v.onerror = () => finish(false);
    v.onloadedmetadata = () => {
      const d = Number.isFinite(v.duration) ? v.duration : 0;
      v.currentTime = Math.min(1, d / 2);
    };
    v.onseeked = () => {
      try {
        const scale = Math.min(1, MAX_SIDE / Math.max(v.videoWidth, v.videoHeight, 1));
        const c = document.createElement('canvas');
        c.width = Math.max(1, Math.round(v.videoWidth * scale));
        c.height = Math.max(1, Math.round(v.videoHeight * scale));
        c.getContext('2d')!.drawImage(v, 0, 0, c.width, c.height);
        c.toBlob(async (blob) => {
          if (!blob) return finish(false);
          try {
            await savePoster(p.id, new Uint8Array(await blob.arrayBuffer()));
            finish(true);
          } catch {
            finish(false);
          }
        }, 'image/jpeg', 0.8);
      } catch {
        finish(false);
      }
    };
    v.src = videoUrl(p.id, p.mtime, p.size);
  });
}
```
