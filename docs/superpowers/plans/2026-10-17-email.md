# Email Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Select photos/videos, click **Email...**, pick recipients by nickname, and send them (resized or original) through the user's own email account over SMTP.

**Architecture:** Validation types live in `pixie-core`; contacts and the non-secret account settings live in the library database (`pixie-index`, V4 migration). A new `pixie-mail` crate owns everything about mail: providers, recipient resolution, text checks, attachment preparation (resize through `pixie-image`), message building and sending behind two small traits (`Mailer`, `SecretStore`) so tests use fakes; the real ones wrap `lettre` and `keyring`. Tauri commands expose it; Svelte dialogs (account settings, contacts, compose) drive it. The account setup and a real test send are built and tried **before** the compose dialog (Task 6 checkpoint).

**Tech Stack:** Rust (`lettre` 0.11 with `builder`, `smtp-transport`, `rustls-tls`, `hostname`; `keyring` 4), rusqlite, image, Tauri 2, Svelte 5 + TypeScript.

**Spec:** `docs/superpowers/specs/2026-10-17-email-design.md`

## Global Constraints

- **AGENTS.md: never commit or push unless the user says so.** No commit steps.
- Never kill the user's running `pixie-app.exe`; never touch `%APPDATA%\app.pixie.desktop\`. While the app runs use `cargo check -p pixie-app`, not `cargo build`.
- Never run plain `cargo update`. Rust env: `VCPKG_ROOT=C:/work/vcpkg-pixie`, `VCPKGRS_TRIPLET=x64-windows-static-md`, `CARGO_RESOLVER_INCOMPATIBLE_RUST_VERSIONS=fallback`. Adding `lettre` and `keyring` re-resolves part of `Cargo.lock`; if cargo says a package needs a newer rustc than 1.89, stop and pin an older compatible version (do NOT upgrade tauri). A spike showed `lettre 0.11.23` and `keyring 4.2.0` build on 1.89.
- **Tooling quirk:** bash heredocs with apostrophes break in this harness; write files and python edit scripts with the Write tool. Preserve line endings: `src-tauri/src/lib.rs` and `ui/src/lib/api.ts` are CRLF, most other files LF (check with `git show HEAD:<file>`).
- **The password** is read from the user's own input in the app only. Never ask the user to paste it into the chat, never log it, never put it in events, errors, the database or test output. Live tests read credentials from environment variables the user sets themselves and are `#[ignore]`.
- Limits: at most 50 attachments, 50 recipients, subject 1-200 characters, message at most 5,000 characters, nickname 1-40 characters, email at most 254 characters.
- Resize presets: Small 1600 px, Medium 2400 px (longer side, never enlarged), JPEG quality 85, no metadata. Encoded size = bytes x 4/3 plus 2 KB; compare against the provider limit.
- Provider presets (host, port, security, limit MB): gmail `smtp.gmail.com` 587 starttls 25; icloud `smtp.mail.me.com` 587 starttls 20; yahoo `smtp.mail.yahoo.com` 587 starttls 25; outlook `smtp-mail.outlook.com` 587 starttls 20; other (user supplied, default 20 MB).
- Only encrypted connections with certificate verification; no plaintext fallback.

## Review Focus

- Header injection through nickname, display name, subject, message or file names (CR/LF, quotes, angle brackets).
- The password never appears in logs, events, errors, the database or test output; deleting the account deletes the stored secret.
- Large selections: attachments are prepared one at a time; the 50-item and size limits hold; memory stays near the limit.
- Double click on Send; closing the dialog or app mid-send.
- A contact deleted or edited while the compose dialog is open (recipients are re-resolved by the backend).
- Selection is index-based: the backend must refuse a send when the indexes no longer resolve to the same number of items.
- HEIC and rotated photos in the resize path; videos near or over the limit.
- Failure messages: refused login, wrong host/port, no network, server says too large.

use crate::{PixieError, Result};
use serde::{Deserialize, Serialize};

pub const MAX_ATTACHMENTS: usize = 50;

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Contact {
    pub id: i64,
    pub nickname: String,
    pub name: Option<String>,
    pub email: String,
}

/// A contact being added (`id: None`) or edited.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct NewContact {
    pub id: Option<i64>,
    pub nickname: String,
    pub name: Option<String>,
    pub email: String,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum MailSecurity {
    Starttls,
    Ssl,
}

/// Non-secret settings of the one mail account. The password lives in the credential store.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct MailAccount {
    pub display_name: Option<String>,
    pub email: String,
    pub provider: String,
    pub host: String,
    pub port: u16,
    pub security: MailSecurity,
    pub limit_mb: u32,
}

fn bad(msg: &str) -> PixieError {
    PixieError::Invalid(msg.into())
}

/// Plain ASCII addresses only: one `@`, a dotted domain, no spaces, quotes, brackets, separators
/// or control characters. Anything that could add a header or a second recipient is rejected.
pub fn validate_email(s: &str) -> Result<String> {
    let s = s.trim();
    if s.is_empty() || s.len() > 254 {
        return Err(bad("That email address is not valid."));
    }
    let ok_chars = s.chars().all(|c| c.is_ascii_alphanumeric() || "._%+-@".contains(c));
    let (local, domain) = s.split_once('@').ok_or_else(|| bad("That email address is not valid."))?;
    let domain_ok = domain.contains('.')
        && !domain.starts_with(['.', '-'])
        && !domain.ends_with(['.', '-'])
        && !domain.contains("..")
        && !domain.contains('@')
        && !domain.contains(['%', '+', '_'])
        && domain.len() <= 253;
    if !ok_chars || local.is_empty() || local.len() > 64 || !domain_ok {
        return Err(bad("That email address is not valid."));
    }
    Ok(s.to_string())
}

pub fn validate_nickname(s: &str) -> Result<String> {
    let s = s.trim();
    if s.is_empty() || s.chars().count() > 40 {
        return Err(bad("A nickname must be 1 to 40 characters."));
    }
    if s.chars().any(|c| c.is_control() || ",;<>\"".contains(c)) {
        return Err(bad("A nickname cannot contain commas, semicolons, quotes, angle brackets or line breaks."));
    }
    Ok(s.to_string())
}

/// A DNS host name: letters, digits, dots and hyphens.
pub fn validate_host(s: &str) -> Result<String> {
    let s = s.trim().to_ascii_lowercase();
    let ok = !s.is_empty()
        && s.len() <= 253
        && s.chars().all(|c| c.is_ascii_alphanumeric() || c == '.' || c == '-')
        && !s.starts_with(['.', '-'])
        && !s.contains("..");
    if ok { Ok(s) } else { Err(bad("The mail server name is not valid.")) }
}

/// Free text that ends up in a header (display name, subject): no control characters, bounded.
pub fn validate_header_text(s: &str, max: usize, what: &str) -> Result<String> {
    let s = s.trim();
    if s.chars().count() > max || s.chars().any(|c| c.is_control()) {
        return Err(PixieError::Invalid(format!("The {what} is too long or contains line breaks.")));
    }
    Ok(s.to_string())
}

    pub fn list_contacts(&self) -> Result<Vec<Contact>> {
        let c = self.conn();
        let mut s = c.prepare("SELECT id, nickname, name, email FROM contacts ORDER BY nickname COLLATE NOCASE").map_err(db_err)?;
        let rows = s
            .query_map([], |r| Ok(Contact { id: r.get(0)?, nickname: r.get(1)?, name: r.get(2)?, email: r.get(3)? }))
            .map_err(db_err)?
            .collect::<std::result::Result<Vec<_>, _>>()
            .map_err(db_err)?;
        Ok(rows)
    }

    pub fn get_contact(&self, id: i64) -> Result<Option<Contact>> {
        self.conn()
            .query_row("SELECT id, nickname, name, email FROM contacts WHERE id = ?1", params![id], |r| {
                Ok(Contact { id: r.get(0)?, nickname: r.get(1)?, name: r.get(2)?, email: r.get(3)? })
            })
            .optional()
            .map_err(db_err)
    }

    pub fn save_contact(&self, c: &NewContact) -> Result<Contact> {
        let nickname = validate_nickname(&c.nickname)?;
        let email = validate_email(&c.email)?;
        let name = match c.name.as_deref().map(str::trim).filter(|n| !n.is_empty()) {
            Some(n) => Some(validate_header_text(n, 100, "name")?),
            None => None,
        };
        let conn = self.conn();
        let res = match c.id {
            Some(id) => conn.execute(
                "UPDATE contacts SET nickname = ?1, name = ?2, email = ?3 WHERE id = ?4",
                params![nickname, name, email, id],
            ).map(|_| id),
            None => conn
                .execute("INSERT INTO contacts (nickname, name, email) VALUES (?1, ?2, ?3)", params![nickname, name, email])
                .map(|_| conn.last_insert_rowid()),
        };
        let id = res.map_err(|e| match e {
            rusqlite::Error::SqliteFailure(f, _) if f.code == rusqlite::ErrorCode::ConstraintViolation => {
                PixieError::Invalid(format!("There is already a contact called \"{nickname}\"."))
            }
            other => db_err(other),
        })?;
        drop(conn);
        self.get_contact(id)?.ok_or_else(|| PixieError::NotFound("contact".into()))
    }

    pub fn delete_contact(&self, id: i64) -> Result<()> {
        self.conn().execute("DELETE FROM contacts WHERE id = ?1", params![id]).map_err(db_err)?;
        Ok(())
    }

    pub fn get_mail_account(&self) -> Result<Option<MailAccount>> {
        self.conn()
            .query_row(
                "SELECT display_name, email, provider, host, port, security, limit_mb FROM mail_account WHERE id = 1",
                [],
                |r| {
                    let security: String = r.get(5)?;
                    Ok(MailAccount {
                        display_name: r.get(0)?, email: r.get(1)?, provider: r.get(2)?, host: r.get(3)?,
                        port: r.get::<_, i64>(4)? as u16,
                        security: if security == "ssl" { MailSecurity::Ssl } else { MailSecurity::Starttls },
                        limit_mb: r.get::<_, i64>(6)? as u32,
                    })
                },
            )
            .optional()
            .map_err(db_err)
    }

    pub fn save_mail_account(&self, a: &MailAccount) -> Result<()> {
        let email = validate_email(&a.email)?;
        let host = validate_host(&a.host)?;
        let display = match a.display_name.as_deref().map(str::trim).filter(|n| !n.is_empty()) {
            Some(n) => Some(validate_header_text(n, 100, "name")?),
            None => None,
        };
        if a.port == 0 {
            return Err(PixieError::Invalid("The port must be between 1 and 65535.".into()));
        }
        if !(1..=100).contains(&a.limit_mb) {
            return Err(PixieError::Invalid("The size limit must be between 1 and 100 MB.".into()));
        }
        let provider = validate_header_text(&a.provider, 20, "provider")?;
        let security = if a.security == MailSecurity::Ssl { "ssl" } else { "starttls" };
        self.conn()
            .execute(
                "INSERT OR REPLACE INTO mail_account (id, display_name, email, provider, host, port, security, limit_mb)
                 VALUES (1, ?1, ?2, ?3, ?4, ?5, ?6, ?7)",
                params![display, email, provider, host, a.port as i64, security, a.limit_mb as i64],
            )
            .map_err(db_err)?;
        Ok(())
    }

    pub fn delete_mail_account(&self) -> Result<()> {
        self.conn().execute("DELETE FROM mail_account WHERE id = 1", []).map_err(db_err)?;
        Ok(())
    }

    /// The items at these positions of the current listing, in the order asked. Positions past the end
    /// or negative are dropped, so the caller must compare the count with what it asked for
    /// (selection is by position and the library can change underneath it). At most 200 positions.
    pub fn photos_at(&self, q: &PhotoQuery, indexes: &[i64]) -> Result<Vec<Photo>> {
        if indexes.len() > 200 {
            return Err(PixieError::Invalid("Too many items selected.".into()));
        }
        let mut out = Vec::with_capacity(indexes.len());
        for &i in indexes {
            if i < 0 {
                continue;
            }
            if let Some(p) = self.list_photos_in(q, i, 1)?.into_iter().next() {
                out.push(p);
            }
        }
        Ok(out)
    }

    pub name: Option<String>,
    pub email: String,

/// Turn what the dialog sent into addresses. Contacts are looked up again here (one may have been
/// edited or deleted while the dialog was open); plain addresses are validated; duplicates collapse.
pub fn resolve_recipients(refs: &[RecipientRef], contacts: &[Contact]) -> Result<Vec<Resolved>> {
    if refs.is_empty() {
        return Err(PixieError::Invalid("Choose at least one person to send to.".into()));
    }
    if refs.len() > MAX_RECIPIENTS {
        return Err(PixieError::Invalid(format!("You can send to at most {MAX_RECIPIENTS} people at once.")));
    }
    let mut out: Vec<Resolved> = Vec::new();
    for r in refs {
        let item = match (r.contact_id, r.email.as_deref()) {
            (Some(id), _) => {
                let c = contacts
                    .iter()
                    .find(|c| c.id == id)
                    .ok_or_else(|| PixieError::Invalid("One of the contacts no longer exists. Pick the recipients again.".into()))?;
                let name = c.name.as_deref().and_then(|n| validate_header_text(n, 100, "name").ok()).filter(|n| !n.is_empty());
                Resolved { name: name.or_else(|| Some(c.nickname.clone())), email: c.email.clone() }
            }
            (None, Some(e)) => Resolved { name: None, email: validate_email(e)? },
            (None, None) => return Err(PixieError::Invalid("A recipient is empty.".into())),
        };
        if !out.iter().any(|o| o.email.eq_ignore_ascii_case(&item.email)) {
            out.push(item);
        }
    }
    Ok(out)
}

use std::collections::HashSet;

pub fn check_subject(s: &str) -> Result<String> {
    let s = validate_header_text(s, 200, "subject")?;
    if s.is_empty() {
        return Err(PixieError::Invalid("Please give the email a subject.".into()));
    }
    Ok(s)
}

pub fn check_body(s: &str) -> Result<String> {
    let s = s.replace("\r\n", "\n").replace('\r', "\n");
    if s.chars().count() > 5000 {
        return Err(PixieError::Invalid("The message is longer than 5,000 characters.".into()));
    }
    if s.chars().any(|c| c.is_control() && c != '\n' && c != '\t') {
        return Err(PixieError::Invalid("The message contains characters that cannot be sent.".into()));
    }
    Ok(s)
}

/// A file name that is safe to put in a header: no path, no separators or control characters, no
/// leading dot, bounded length, and not used before in `taken`. `ext` replaces the extension.
pub fn safe_filename(name: &str, ext: Option<&str>, taken: &mut HashSet<String>) -> String {
    let base = name.rsplit(['/', '\\']).next().unwrap_or("");
    let (stem, own_ext) = match base.rfind('.') {
        Some(i) if i > 0 => (&base[..i], &base[i + 1..]),
        _ => (base, ""),
    };
    let clean = |s: &str| -> String {
        s.chars().map(|c| if c.is_control() || "\\/:*?\"<>|".contains(c) { '_' } else { c }).collect()
    };
    let mut stem = clean(stem).trim_start_matches('.').trim().to_string();
    if stem.is_empty() {
        stem = "attachment".into();
    }
    stem.truncate(stem.char_indices().take(100).last().map(|(i, c)| i + c.len_utf8()).unwrap_or(0));
    let ext = clean(ext.unwrap_or(own_ext));
    let join = |s: &str| if ext.is_empty() { s.to_string() } else { format!("{s}.{ext}") };
    let mut candidate = join(&stem);
    let mut n = 2;
    while !taken.insert(candidate.to_lowercase()) {
        candidate = join(&format!("{stem} ({n})"));
        n += 1;
    }
    candidate
}

/// Size on the wire: base64 grows binary by 4/3; plus a little for headers.
pub fn encoded_size(attachment_bytes: &[u64]) -> u64 {
    attachment_bytes.iter().sum::<u64>() * 4 / 3 + 2048
}

pub fn check_limit(encoded: u64, limit_mb: u32) -> Result<()> {
    if encoded > limit_mb as u64 * 1024 * 1024 {
        return Err(PixieError::Invalid(format!(
            "This email would be about {:.1} MB, more than the {limit_mb} MB your mail provider allows. Choose a smaller size or fewer items.",
            encoded as f64 / (1024.0 * 1024.0)
        )));
    }
    Ok(())
}

use crate::text::safe_filename;
use image::codecs::jpeg::JpegEncoder;
use pixie_core::{MediaKind, PixieError, Photo, Result};
use serde::Deserialize;
use std::collections::HashSet;
use std::path::Path;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum SizeChoice {
    Small,
    Medium,
    Original,
}

impl SizeChoice {
    pub fn edge(self) -> Option<u32> {
        match self {
            SizeChoice::Small => Some(1600),
            SizeChoice::Medium => Some(2400),
            SizeChoice::Original => None,
        }
    }
}

pub struct Attachment {
    pub filename: String,
    pub content_type: String,
    pub bytes: Vec<u8>,
}

fn unreadable(name: &str) -> PixieError {
    PixieError::Invalid(format!("Pixie could not read \"{name}\" to attach it. It may be damaged or moved."))
}

fn mime_of(path: &Path) -> &'static str {
    match path.extension().and_then(|e| e.to_str()).map(|e| e.to_ascii_lowercase()).as_deref() {
        Some("jpg") | Some("jpeg") => "image/jpeg",
        Some("png") => "image/png",
        Some("webp") => "image/webp",
        Some("tif") | Some("tiff") => "image/tiff",
        Some("heic") => "image/heic",
        Some("heif") => "image/heif",
        Some("mov") => "video/quicktime",
        Some("m4v") => "video/x-m4v",
        Some("mp4") => "video/mp4",
        _ => "application/octet-stream",
    }
}

/// One attachment, prepared from the file on disk. Photos are shrunk (upright, JPEG, no metadata)
/// unless `Original`; videos are always sent as they are. The original file is never changed.
pub fn prepare_attachment(photo: &Photo, choice: SizeChoice, taken: &mut HashSet<String>) -> Result<Attachment> {
    let path = Path::new(&photo.path);
    let shown = path.file_name().and_then(|n| n.to_str()).unwrap_or("file").to_string();
    let resize = photo.meta.kind == MediaKind::Photo && choice.edge().is_some();
    if !resize {
        let bytes = std::fs::read(path).map_err(|_| unreadable(&shown))?;
        return Ok(Attachment { filename: safe_filename(&shown, None, taken), content_type: mime_of(path).into(), bytes });
    }
    let edge = choice.edge().unwrap();
    let img = pixie_image::decode::decode_scaled(path, edge).map_err(|_| unreadable(&shown))?;
    let img = if img.width().max(img.height()) > edge { img.resize(edge, edge, image::imageops::FilterType::Lanczos3) } else { img };
    let mut bytes = Vec::new();
    JpegEncoder::new_with_quality(&mut bytes, 85)
        .encode_image(&img.to_rgb8())
        .map_err(|_| unreadable(&shown))?;
    Ok(Attachment { filename: safe_filename(&shown, Some("jpg"), taken), content_type: "image/jpeg".into(), bytes })
}

use lettre::message::{header::ContentType, Attachment as MimeAttachment, Mailbox, MultiPart, SinglePart};
use lettre::{Address, Message};
use pixie_core::{MailAccount, PixieError, Result};

fn mailbox(name: Option<&str>, email: &str) -> Result<Mailbox> {
    let addr: Address = email.parse().map_err(|_| PixieError::Invalid("That email address is not valid.".into()))?;
    Ok(Mailbox::new(name.map(str::to_string), addr))
}

pub fn build_message(account: &MailAccount, to: &[Resolved], subject: &str, body: &str, attachments: Vec<Attachment>) -> Result<Message> {
    let mut b = Message::builder().from(mailbox(account.display_name.as_deref(), &account.email)?).subject(subject);
    for r in to {
        b = b.to(mailbox(r.name.as_deref(), &r.email)?);
    }
    let mut multi = MultiPart::mixed().singlepart(SinglePart::plain(body.to_string()));
    for a in attachments {
        let ct = ContentType::parse(&a.content_type).map_err(|_| PixieError::Invalid("An attachment has an unsupported type.".into()))?;
        multi = multi.singlepart(MimeAttachment::new(a.filename).body(a.bytes, ct));
    }
    b.multipart(multi).map_err(|_| PixieError::Invalid("The email could not be put together.".into()))
}

fn password(secrets: &dyn SecretStore, account: &MailAccount) -> Result<String, SendFailure> {
    match secrets.get(&account.email) {
        Ok(Some(p)) if !p.is_empty() => Ok(p),
        _ => Err(SendFailure("No password is saved for your email account. Open Email settings and enter it.".into())),
    }

/// Prepare every attachment (one at a time), check the size against the provider limit, send.
/// Returns the addresses it was sent to. Messages in `SendFailure` are plain language and never
/// contain the password or raw server text.
pub fn send_photos(
    mailer: &dyn Mailer,
    secrets: &dyn SecretStore,
    account: &MailAccount,
    req: SendRequest,
    progress: &dyn Fn(Progress),
) -> Result<Vec<String>, SendFailure> {
    if req.photos.is_empty() {
        return Err(SendFailure("Select at least one photo or video to send.".into()));
    }
    if req.photos.len() > MAX_ATTACHMENTS {
        return Err(SendFailure(format!("You can send at most {MAX_ATTACHMENTS} items in one email.")));
    }
    let subject = check_subject(&req.subject)?;
    let body = check_body(&req.message)?;
    let pw = password(secrets, account)?;

    // Cheap pre-check on file sizes (videos and Original are exact; resized photos only get smaller).
    let upper: Vec<u64> = req.photos.iter().map(|p| p.size.max(0) as u64).collect();
    let exact: u64 = req
        .photos
        .iter()
        .zip(&upper)
        .filter(|(p, _)| req.size == SizeChoice::Original || p.meta.kind == pixie_core::MediaKind::Video)
        .map(|(_, s)| *s)
        .sum();
    check_limit(encoded_size(&[exact]), account.limit_mb)?;

    let total = req.photos.len();
    progress(Progress { done: 0, total });
    let mut taken = HashSet::new();
    let mut atts = Vec::with_capacity(total);
    for (i, p) in req.photos.iter().enumerate() {
        atts.push(prepare_attachment(p, req.size, &mut taken)?);
        progress(Progress { done: i + 1, total });
    }
    let sizes: Vec<u64> = atts.iter().map(|a| a.bytes.len() as u64).collect();
    check_limit(encoded_size(&sizes), account.limit_mb)?;

    let message = build_message(account, &req.to, &subject, &body, atts)?;
    mailer.send(account, &pw, &message).map_err(|e| SendFailure(e.user_message(hint(account))))?;
    Ok(req.to.iter().map(|r| r.email.clone()).collect())
}

use crate::error::MailError;
use crate::traits::Mailer;
use lettre::transport::smtp::authentication::Credentials;
use lettre::{Message, SmtpTransport, Transport};
use pixie_core::{MailAccount, MailSecurity};
use std::time::Duration;

#[derive(Debug, Clone, Copy)]
pub struct SmtpFailure {
    pub code: Option<u16>,
    pub timeout: bool,
    pub tls: bool,
    pub connection: bool,
}

pub fn classify(f: &SmtpFailure) -> MailError {
    if f.timeout {
        return MailError::Timeout;
    }
    if f.tls {
        return MailError::Tls;
    }
    match f.code {
        Some(530 | 534 | 535 | 538) => MailError::Auth,
        Some(552 | 554) => MailError::TooLarge,
        Some(550 | 551 | 553 | 501) => MailError::RecipientRejected,
        Some(_) => MailError::Other,
        None if f.connection => MailError::Connect,
        None => MailError::Other,
    }
}

fn failure_of(e: &lettre::transport::smtp::Error) -> SmtpFailure {
    SmtpFailure {
        code: e.status().and_then(|c| c.to_string().parse().ok()),
        timeout: e.is_timeout(),
        tls: e.is_tls(),
        connection: e.is_client() || e.is_transient() && e.status().is_none(),
    }
}

pub struct SmtpMailer;

impl Mailer for SmtpMailer {
    fn send(&self, a: &MailAccount, password: &str, m: &Message) -> Result<(), MailError> {
        let builder = match a.security {
            MailSecurity::Starttls => SmtpTransport::starttls_relay(&a.host),
            MailSecurity::Ssl => SmtpTransport::relay(&a.host),
        }
        .map_err(|_| MailError::Connect)?;
        let transport = builder
            .port(a.port)
            .credentials(Credentials::new(a.email.clone(), password.to_string()))
            .timeout(Some(Duration::from_secs(60))) // per network operation
            .build();
        transport.send(m).map(|_| ()).map_err(|e| {
            // Server text can contain the user name and more: log the category only, never the password.
            eprintln!("[mail] send failed: {:?}", failure_of(&e));
            classify(&failure_of(&e))
        })
    }
}

const SERVICE: &str = "Pixie mail";

/// The password lives in the operating system's credential store (Windows Credential Manager,
/// macOS Keychain), keyed by the account's email address. Never in a file or the database.
pub struct OsSecrets;

fn err(_: keyring::Error) -> PixieError {
    PixieError::Invalid("Pixie could not use the system password store.".into())
}

impl SecretStore for OsSecrets {
    fn get(&self, key: &str) -> Result<Option<String>> {
        match keyring::Entry::new(SERVICE, key).map_err(err)?.get_password() {
            Ok(p) => Ok(Some(p)),
            Err(keyring::Error::NoEntry) => Ok(None),
            Err(e) => Err(err(e)),
        }
    }
    fn set(&self, key: &str, secret: &str) -> Result<()> {
        keyring::Entry::new(SERVICE, key).map_err(err)?.set_password(secret).map_err(err)
    }
    fn delete(&self, key: &str) -> Result<()> {
        match keyring::Entry::new(SERVICE, key).map_err(err)?.delete_credential() {
            Ok(()) | Err(keyring::Error::NoEntry) => Ok(()),
            Err(e) => Err(err(e)),
        }
    }
}

```ts
// recipients.test.ts
const contacts: Contact[] = [
  { id: 1, nickname: 'dad', name: 'Frank Moore', email: 'dad@example.com' },
  { id: 2, nickname: 'Simon', name: null, email: 'si@example.com' },
  { id: 3, nickname: 'sis', name: 'Sally Moore', email: 'sis@example.com' },
];
describe('suggest', () => {
  it('prefers nickname prefixes, then substrings of nicknames and names, ignoring case', () => {
    expect(suggest(contacts, 'si', new Set()).map((c) => c.nickname)).toEqual(['Simon', 'sis']);
    expect(suggest(contacts, 'moo', new Set()).map((c) => c.nickname)).toEqual(['dad', 'sis']);
    expect(suggest(contacts, 'DAD', new Set()).map((c) => c.nickname)).toEqual(['dad']);
  });
  it('skips chosen contacts, and shows everyone (limited) for empty text', () => {
    expect(suggest(contacts, 'si', new Set([2])).map((c) => c.nickname)).toEqual(['sis']);
    expect(suggest(contacts, '', new Set()).length).toBe(3);
    const many = Array.from({ length: 20 }, (_, i) => ({ id: i, nickname: `n${i}`, name: null, email: `n${i}@x.com` }));
    expect(suggest(many, '', new Set()).length).toBe(6);
  });
});
describe('parseTyped', () => {
  it('turns nicknames into contacts, addresses into addresses and the rest into unknowns', () => {
    const t = parseTyped('dad, a@b.com; Simon\nwho', contacts);
    expect(t.map((x) => x.kind)).toEqual(['contact', 'address', 'contact', 'unknown']);
    expect(parseTyped('  ', contacts)).toEqual([]);
  });
  it('looksLikeEmail is a quick shape check only', () => {
    expect(looksLikeEmail('a@b.co')).toBe(true);
    for (const s of ['a', 'a@b', '@b.com', 'a b@c.com']) expect(looksLikeEmail(s)).toBe(false);
  });
});
```

// mailText.test.ts
describe('defaultSubject', () => {
  it('names the count and the date or date range', () => {
    const p = (t: number | null) => ({ taken_at: t } as Photo);
    expect(defaultSubject([p(Date.UTC(2024, 5, 3, 14) / 1000)])).toBe('1 photo from Mon 3 Jun 2024'.replace('Mon', 'Mon'));
    expect(defaultSubject([p(Date.UTC(2024, 5, 3) / 1000), p(Date.UTC(2024, 5, 3, 9) / 1000)])).toMatch(/^2 photos from /);
    expect(defaultSubject([p(Date.UTC(2024, 5, 3) / 1000), p(Date.UTC(2024, 6, 9) / 1000)])).toMatch(/^2 photos from 3 Jun 2024 to 9 Jul 2024$/);
    expect(defaultSubject([p(null), p(null)])).toBe('2 photos');
  });
});
describe('size estimate and limit state', () => {
  const photo = (w: number, h: number, size: number, kind: 'photo' | 'video' = 'photo') => ({ width: w, height: h, size, kind } as Photo);
  it('original is the file size; small shrinks big photos and never exceeds the file', () => {
    expect(estimateBytes(photo(4000, 3000, 5_000_000), 'original')).toBe(5_000_000);
    const small = estimateBytes(photo(4000, 3000, 5_000_000), 'small');
    expect(small).toBeLessThan(1_000_000);
    expect(estimateBytes(photo(400, 300, 30_000), 'small')).toBeLessThanOrEqual(30_000);
    expect(estimateBytes(photo(100, 100, 1, 'video'), 'small')).toBe(1); // videos are sent as they are
  });
  it('flags near and over the provider limit including the base64 overhead', () => {
    expect(sizeState(5 * 1024 * 1024, 20)).toBe('ok');
    expect(sizeState(13 * 1024 * 1024, 20)).toBe('near'); // x 4/3 is about 17.3 MB, over 80%
    expect(sizeState(16 * 1024 * 1024, 20)).toBe('over'); // about 21.3 MB
    expect(formatMb(1536 * 1024)).toBe('1.5 MB');
  });
});
