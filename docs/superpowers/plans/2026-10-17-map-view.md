# Map View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A map of all geotagged photos and videos (clusters that split on zoom) above the normal grid, which shows only what is inside the visible map area.

**Architecture:** A bounding-box filter joins the existing folder and kind filters in `PhotoQuery`/`Filter`, so the grid, counts, day groups, viewer and details all work unchanged on a bounds-filtered view. A new `list_geo_points` command feeds a front-end clustering module (pure functions on Web Mercator pixel cells). `PhotoMap.svelte` draws clusters on the existing Leaflet + tile service and reports debounced bounds to `App.svelte`, which owns the `view`.

**Tech Stack:** Rust (rusqlite, tauri 2), Svelte 5 + TypeScript, Leaflet 1.9.4 (already installed).

**Spec:** `docs/superpowers/specs/2026-10-17-map-view-design.md`

## Global Constraints

- **AGENTS.md: never commit or push unless the user says so.** This plan has no commit steps.
- Never kill the user's running `pixie-app.exe`; never touch `%APPDATA%\app.pixie.desktop\`. While the app runs use `cargo check -p pixie-app`, not `cargo build`.
- Never run plain `cargo update`. Rust env per session: `VCPKG_ROOT=C:/work/vcpkg-pixie`, `VCPKGRS_TRIPLET=x64-windows-static-md`, `CARGO_RESOLVER_INCOMPATIBLE_RUST_VERSIONS=fallback`.
- **Tooling quirk:** bash heredocs containing apostrophes break in this harness. Write multi-line files and python edit scripts with the Write tool, then run them. Preserve each file's existing line endings (`git show HEAD:<file>` to check; src-tauri/src/lib.rs and ui/src/lib/api.ts are CRLF, most others LF).
- Cluster cell size 60 px; click-to-zoom level for a single pin or stacked cluster is 17; grid refresh debounce 200 ms; bounds are rounded to 5 decimals; map is 45% of the centre pane with a 220 px minimum.
- A bounds filter that is invalid (non-finite, south > north) matches nothing.
- Items without GPS never match a bounds filter.

## Review Focus

- Antimeridian (west > east) and polar bounds, including a view wider than 360 degrees (zoomed far out).
- Many items at one coordinate: must not loop or produce an unclickable cluster.
- 100,000 located items: clustering time, marker count, paged listing under a bounds filter.
- Pan/zoom storms: only the latest bounds applies; no marker leaks; no tile request pile-up.
- Changing kind or folder, leaving map mode, or a scan finishing while the map is open.
- Selection, viewer and details under a bounds-filtered view.

```rust
/// A latitude/longitude rectangle. `west > east` means it crosses the antimeridian.
#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
pub struct Bounds {
    pub south: f64,
    pub west: f64,
    pub north: f64,
    pub east: f64,
}

impl Bounds {
    pub fn wraps(&self) -> bool {
        self.west > self.east
    }

    /// Clamp to valid coordinates. `None` for non-finite values or `south > north`.
    /// A rectangle 360 degrees wide or more becomes the full longitude range.
    pub fn normalized(&self) -> Option<Bounds> {
        let all = [self.south, self.west, self.north, self.east];
        if all.iter().any(|v| !v.is_finite()) || self.south > self.north {
            return None;
        }
        let lat = |v: f64| v.clamp(-90.0, 90.0);
        let lon = |v: f64| v.clamp(-180.0, 180.0);
        let (south, north) = (lat(self.south), lat(self.north));
        let width = if self.west <= self.east { self.east - self.west } else { self.east + 360.0 - self.west };
        if width >= 360.0 {
            return Some(Bounds { south, west: -180.0, north, east: 180.0 });
        }
        Some(Bounds { south, west: lon(self.west), north, east: lon(self.east) })
    }
}

/// Where one photo or video was taken, for the map.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct GeoPoint {
    pub id: PhotoId,
    pub lat: f64,
    pub lon: f64,
}
```

```rust
struct Filter {
    folder: Option<i64>,
    kind: Option<i64>,
    /// `Some(None)` is an invalid box that matches nothing.
    bounds: Option<Option<Bounds>>,
}

impl Filter {
    fn of(q: &PhotoQuery) -> Filter {
        Filter {
            folder: q.folder_id,
            kind: q.kind.map(|k| if k == MediaKind::Video { 1 } else { 0 }),
            bounds: q.bounds.map(|b| b.normalized()),
        }
    }
    fn sql(&self) -> String {
        let mut s = String::new();
        if self.folder.is_some() {
            s.push_str(" AND folder_id = :folder");
        }
        if self.kind.is_some() {
            s.push_str(" AND kind = :kind");
        }
        match &self.bounds {
            None => {}
            Some(None) => s.push_str(" AND 0"),
            Some(Some(b)) if b.wraps() => {
                s.push_str(" AND gps_lat BETWEEN :south AND :north AND (gps_lon >= :west OR gps_lon <= :east)")
            }
            Some(Some(_)) => s.push_str(" AND gps_lat BETWEEN :south AND :north AND gps_lon BETWEEN :west AND :east"),
        }
        s
    }
    fn params(&self) -> Vec<(&'static str, &dyn rusqlite::ToSql)> {
        let mut v: Vec<(&'static str, &dyn rusqlite::ToSql)> = Vec::new();
        if let Some(f) = &self.folder {
            v.push((":folder", f));
        }
        if let Some(k) = &self.kind {
            v.push((":kind", k));
        }
        if let Some(Some(b)) = &self.bounds {
            v.push((":south", &b.south));
            v.push((":north", &b.north));
            v.push((":west", &b.west));
            v.push((":east", &b.east));
        }
        v
    }
}
```

```rust
    /// Every non-missing item with a location, for the map. Honours the folder and kind filters.
    pub fn list_geo_points(&self, folder_id: Option<FolderId>, kind: Option<MediaKind>) -> Result<Vec<GeoPoint>> {
        let q = PhotoQuery { folder_id, kind, ..Default::default() };
        let filter = Filter::of(&q);
        let sql = format!(
            "SELECT id, gps_lat, gps_lon FROM photos WHERE missing = 0 AND gps_lat IS NOT NULL AND gps_lon IS NOT NULL{} ORDER BY id",
            filter.sql()
        );
        let c = self.conn();
        let mut s = c.prepare(&sql).map_err(db_err)?;
        let rows = s
            .query_map(filter.params().as_slice(), |r| Ok(GeoPoint { id: r.get(0)?, lat: r.get(1)?, lon: r.get(2)? }))
            .map_err(db_err)?
            .collect::<std::result::Result<Vec<_>, _>>()
            .map_err(db_err)?;
        Ok(rows)
    }
```

```ts
/** Calls `fn` once, `ms` after the last call, with the last call's arguments. */
export function debounce<A extends unknown[]>(fn: (...a: A) => void, ms: number) {
  let timer: ReturnType<typeof setTimeout> | undefined;
  const wrapped = (...a: A) => {
    clearTimeout(timer);
    timer = setTimeout(() => { timer = undefined; fn(...a); }, ms);
  };
  wrapped.cancel = () => { clearTimeout(timer); timer = undefined; };
  return wrapped;
}
```

```ts
export interface GeoPoint { id: number; lat: number; lon: number }
/** A latitude/longitude rectangle; west > east means it crosses the antimeridian. */
export interface Bounds { south: number; west: number; north: number; east: number }
export interface MapView { lat: number; lon: number; zoom: number }

const MAX_LAT = 85.0511287798; // the Web Mercator limit
const round5 = (v: number) => Math.round(v * 1e5) / 1e5;

/** Web Mercator world pixel position at a zoom level (256 px tiles). */
export function project(lat: number, lon: number, zoom: number): { x: number; y: number } {
  const size = 256 * 2 ** zoom;
  const la = Math.max(-MAX_LAT, Math.min(MAX_LAT, lat));
  const s = Math.sin((la * Math.PI) / 180);
  return {
    x: ((lon + 180) / 360) * size,
    y: (0.5 - Math.log((1 + s) / (1 - s)) / (4 * Math.PI)) * size,
  };
}

export function inBounds(lat: number, lon: number, b: Bounds): boolean {
  if (lat < b.south || lat > b.north) return false;
  return b.west <= b.east ? lon >= b.west && lon <= b.east : lon >= b.west || lon <= b.east;
}

const wrapLon = (v: number) => ((((v + 180) % 360) + 360) % 360) - 180;

/** Bounds as Leaflet reports them (longitudes may leave +-180) -> a valid, rounded box, or null. */
export function boundsOfView(south: number, west: number, north: number, east: number): Bounds | null {
  if (![south, west, north, east].every(Number.isFinite) || south > north) return null;
  const lat = (v: number) => Math.max(-90, Math.min(90, v));
  const s = round5(lat(south)), n = round5(lat(north));
  if (east - west >= 360) return { south: s, west: -180, north: n, east: 180 };
  let w = wrapLon(west), e = wrapLon(east);
  // wrapLon maps +180 to -180; keep a box that ends exactly on the line ending on it
  if (east === 180 || (east > 180 && e === -180)) e = 180 - 0;
  return { south: s, west: round5(w), north: n, east: round5(e) };
}

export function sameBounds(a: Bounds | null, b: Bounds | null): boolean {
  if (a === null || b === null) return a === b;
  return a.south === b.south && a.west === b.west && a.north === b.north && a.east === b.east;
}

export interface Cluster {
  count: number;
  /** Centroid. */
  lat: number;
  lon: number;
  /** The item's id when `count` is 1. */
  id: number | null;
  /** Extent of the members. */
  south: number; west: number; north: number; east: number;
  /** Several items at (almost) one spot: zooming in will not separate them. */
  stacked: boolean;
}

const STACK_DEG = 1e-5; // about a metre

/**
 * Group points into pixel cells of `cellPx` at `zoom`. Only points inside `bounds` (plus a margin
 * so markers just off screen exist when the user pans) are clustered.
 */
export function clusterPoints(points: GeoPoint[], zoom: number, bounds: Bounds | null, cellPx = 60): Cluster[] {
  const area = bounds && !(bounds.west > bounds.east) ? widen(bounds, 0.25) : bounds;
  const cells = new Map<string, { n: number; sLat: number; sLon: number; id: number; s: number; w: number; nn: number; e: number }>();
  for (const p of points) {
    if (area && !inBounds(p.lat, p.lon, area)) continue;
    const { x, y } = project(p.lat, p.lon, zoom);
    const key = `${Math.floor(x / cellPx)}:${Math.floor(y / cellPx)}`;
    const c = cells.get(key);
    if (c) {
      c.n++; c.sLat += p.lat; c.sLon += p.lon;
      if (p.lat < c.s) c.s = p.lat;
      if (p.lat > c.nn) c.nn = p.lat;
      if (p.lon < c.w) c.w = p.lon;
      if (p.lon > c.e) c.e = p.lon;
    } else {
      cells.set(key, { n: 1, sLat: p.lat, sLon: p.lon, id: p.id, s: p.lat, w: p.lon, nn: p.lat, e: p.lon });
    }
  }
  return [...cells.values()].map((c) => ({
    count: c.n,
    lat: c.sLat / c.n,
    lon: c.sLon / c.n,
    id: c.n === 1 ? c.id : null,
    south: c.s, west: c.w, north: c.nn, east: c.e,
    stacked: c.n > 1 && c.nn - c.s < STACK_DEG && c.e - c.w < STACK_DEG,
  }));
}

function widen(b: Bounds, f: number): Bounds {
  const dLat = (b.north - b.south) * f, dLon = (b.east - b.west) * f;
  return {
    south: Math.max(-90, b.south - dLat), north: Math.min(90, b.north + dLat),
    west: Math.max(-180, b.west - dLon), east: Math.min(180, b.east + dLon),
  };
}

export type ClusterTarget =
  | { kind: 'fit'; bounds: Bounds }
  | { kind: 'zoom'; lat: number; lon: number; zoom: number };

/** What clicking a cluster should do. */
export function clusterTarget(c: Cluster): ClusterTarget {
  if (c.count === 1 || c.stacked) return { kind: 'zoom', lat: c.lat, lon: c.lon, zoom: 17 };
  return { kind: 'fit', bounds: { south: c.south, west: c.west, north: c.north, east: c.east } };
}

/** A saved map position may be anything (or corrupt); only a sane one is used. */
export function parseMapView(v: unknown): MapView | null {
  if (typeof v !== 'object' || v === null) return null;
  const { lat, lon, zoom } = v as Record<string, unknown>;
  if (typeof lat !== 'number' || typeof lon !== 'number' || typeof zoom !== 'number') return null;
  if (![lat, lon, zoom].every(Number.isFinite)) return null;
  if (Math.abs(lat) > 90 || Math.abs(lon) > 180 || zoom < 1 || zoom > 19) return null;
  return { lat, lon, zoom };
}
```

```svelte
        const t = clusterTarget(c);

        else map!.fitBounds([[t.bounds.south, t.bounds.west], [t.bounds.north, t.bounds.east]], { padding: [40, 40], maxZoom: 18 });
      });
      markers.addLayer(m);

    if (!map || points.length === 0) return;
    const lats = points.map((p) => p.lat), lons = points.map((p) => p.lon);

    ro.observe(el);
    if (!positioned) fitAll();
    redraw();
    emitBounds(viewBounds());
    return () => {
      ro.disconnect();
      emitBounds.cancel();
      emitMove.cancel();
      map?.remove();
      map = undefined;
    };
```
